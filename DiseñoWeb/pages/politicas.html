Políticas que cuidan el proceso

Condiciones

Un marco claro para cada proyecto

El alcance puede adaptarse a las necesidades del sitio, siempre que las decisiones y cambios se comuniquen y aprueben oportunamente.

01

Alcance de cada proyecto

Antes de comenzar se define qué incluye el diseño: estructura de páginas, estilo visual, textos, imágenes, formularios y funciones necesarias. El alcance depende del objetivo del sitio y debe acordarse con claridad.

02

Límites del diseño

El diseño web no sustituye servicios especializados como asesoría legal, contable, publicitaria o de seguridad informática. La entrega tampoco incluye elementos no acordados previamente.

03

Variables del resultado

El tiempo y la complejidad pueden variar según el número de páginas, productos, integraciones, información disponible, plataforma y nivel de personalización.

04

Responsabilidad del cliente

El cliente debe proporcionar información verdadera, textos, imágenes y datos autorizados. También debe revisar precios, políticas comerciales y datos de productos antes de publicar.

05

Revisiones y cambios

Las revisiones mejoran la propuesta dentro del alcance acordado. Los cambios que agreguen secciones, funciones o contenidos pueden modificar el tiempo y requerir una nueva estimación.

06

Privacidad y comunicación

La información compartida durante el proyecto se utiliza para planear y desarrollar el sitio. Una comunicación clara ayuda a confirmar decisiones y mantener un proceso responsable.
